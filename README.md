# TRACKIFY Mac

Windows bilgisayardaki TRACKIFY'a bağlanan Mac uygulaması.

**İndir:** [son sürüm](https://github.com/mertkurtul16/trackify-indir/releases/latest)

- Apple Silicon (M1/M2/M3/M4): `TRACKIFY-Mac-AppleSilicon.dmg`
- Intel Mac: `TRACKIFY-Mac-Intel.dmg`

İlk açılışta macOS uyarı verirse: Sistem Ayarları › Gizlilik ve Güvenlik › **Yine de Aç**.
